# 广州理工学院 校园网自动登录（CampusNet）

> **这份是什么**：Windows 上自动连校园网的小工具：双击即登录、掉线自动重连，账号密码用 Windows 加密只存本机。
> **只想用它上网？** 看完**第一部分**就够了（5 分钟）。**第二部分是参考资料，平时不用翻。**
> **相关文档**：使用说明 [`docs/使用说明.md`](docs/使用说明.md) · 维护交接 [`docs/维护指南.md`](docs/维护指南.md) · 认证原理 [`Campus Network source code/README.md`](Campus%20Network%20source%20code/README.md)

> 🔐 **本项目不含任何真实凭据**：配置文件已清空，示例里的学号 / 密码 / 本机 MAC / IP 全部是合成的。
> **首次使用请先双击 `FirstTimeSetup.bat`** 重新填一次账号密码。

# 🟢 第一部分 · 用起来

> 这一部分从零开始、照着做就行。看完就能正常上网。

## 🚦 一、到底双击哪个？

| 文件                  | 什么时候用                                                    |
|:--------------------- |:------------------------------------------------------------- |
| `CampusNet.bat`       | **每天都点这个**：自动登录 + 主菜单                           |
| `FirstTimeSetup.bat`  | 第一次使用、换账号、换电脑时                                  |
| `CampusNet_Debug.bat` | 出问题时用：窗口不关，能直接看到报错                          |

窗口**不会再"一闪而过"**：无论成功还是失败都会停住并显示 `Press any key to close this window...`。

> 💡 **小白理解**：`CampusNet.bat` = 微波炉（按一下就热饭）；`FirstTimeSetup.bat` = 菜谱（第一次照着做）；
> `CampusNet_Debug.bat` = 检修口（把盖子打开给你看内部）。

## 🎬 二、三步开始用

### 第 1 步：第一次配置（只做一次）

双击 `FirstTimeSetup.bat`，会弹出一个黑色窗口，**这是正常的，别害怕**。按提示输入：

```
请输入您的学号：2024xxxxxxxxxx
请输入您的校园网密码：********          ← 输入时不显示，是保护隐私，正常输
请再输入一次密码：********
服务器地址：（直接回车用默认）
```

看到「配置已保存」就成了，按任意键关窗。

### 第 2 步：日常使用（每天）

1. **先连网络**：插上网线，或连上校园 Wi-Fi；
2. **双击 `CampusNet.bat`**，等几秒；
3. 看到「登录成功」就可以上网了。

> 💡 主菜单的 8 项**不用背**：平时直接选 `8` 退出就行；排障时常用的是 **4（看日志）/ 5（登录联调）/ 6（网络修复）/ 7（清理 DNS 缓存）**。

### 第 3 步：自己验证一下

打开浏览器访问 [baidu.com](https://www.baidu.com)，能打开就成功了。

> ⚠️ **记住这条**：脚本说成功不算，**能打开网页才算**。脚本正是按这个标准判断的，
> 所以它绝不会把"假登录"报成成功。

## 🎯 三、三种常见场景

### 场景一：每天用（最简单）

把 `CampusNet.bat` 发送到桌面快捷方式（或双击 `CreateDesktopShortcut.ps1` 自动建一个），每次上网前双击它。

### 场景二：开机自动登录（最省事）

1. `Win+R` 输入 `taskschd.msc` 打开任务计划；
2. 新建基本任务：名称自取；触发器选「计算机启动时」或「计算机登录时」；操作选「启动程序」；
3. 「程序或脚本」填 `powershell.exe`；
4. 「添加参数」填 `-NoProfile -ExecutionPolicy Bypass -File "<本目录>\CampusNet_Silent.ps1"`；
5. 完成。

> ⚠️ **开机自启千万不要用 `CampusNet.bat`**：那是交互版，每次开机都会弹窗并一直等你按键。
> 静默版 `CampusNet_Silent.ps1` 无窗口，登录失败也不会打扰你。

#### 💡 小白理解：就像设置闹钟，每天早上自动响铃。

### 场景三：换账号 / 多人共用一台电脑

重新运行 `FirstTimeSetup.bat`，输入新账号密码，旧配置会被覆盖。

## 📶 四、有线还是无线？

**两种都支持**，不用做任何设置：

1. 先连上校园无线（例如 `CampusWiFi`）或插上网线，确认已经拿到 IP；
2. 双击 `CampusNet.bat`，脚本会自己挑出可用的那张网卡；
3. 如果提示"查不到当前 SSID"，**不一定代表没连上**：只要拿到 IP 就会继续登录。

> 小提示：同时插着网线和连着 WiFi 时，脚本会**按"去往门户服务器走哪张网卡"来选**，
> 比"优先有线"更准；选中的网卡与理由会写进日志。

## 🧰 五、出问题了？先看这里

### 30 秒定位：你看到什么，就做什么

| 你看到的现象                        | 先做什么                                                      |
|:----------------------------------- |:------------------------------------------------------------- |
| 双击后**窗口一闪就没**              | 改用 `CampusNet_Debug.bat` 启动（窗口不关，能直接看到报错）   |
| 提示**没有可用网卡**                | 先确认网线插好 / WiFi 连上；仍不行就跑一次**网络修复**（见下） |
| 提示**密码错误 / 账号问题**         | 核对密码；改过密码就重跑 `FirstTimeSetup.bat`                 |
| 提示**已在其他设备登录**            | 去自助服务把别的设备下线：`http://10.0.8.81:8080/Self/login/?302=LI` |
| 提示**成功但就是上不了网**          | 这是"伪登录"，见下方「伪登录」一节                            |
| **插了网线没反应、非要重启电脑**    | 跑**网络修复**（见下）                                        |
| 提示**密码解密失败**                | 配置来自别的用户 / 电脑，删掉 `CampusNet_Config.json` 重跑向导 |
| 其它任何异常                        | 看日志：主菜单选 `4`，或打开 `logs\<今天>\` 文件夹            |

### 两个自救按钮

| 想干什么         | 怎么做                                                                        |
|:---------------- |:----------------------------------------------------------------------------- |
| **网络修复**     | 主菜单选 `6`（或命令行 `-Repair`）：清缓存 → 重拿 DHCP → 必要时重启网卡。**“清 ARP 缓存”与“重启网卡”这两步需要管理员**（右键 `CampusNet.bat` → 以管理员身份运行）；没有管理员时其余步骤照做 |
| **清理 DNS 缓存** | 主菜单选 `7`（或命令行 `-FlushDns`）：只清 DNS 缓存，**不需要管理员**，不会碰网卡和配置 |

> 做完"网络修复"仍拿不到 IP，多半不是本机问题，而是**网络侧没放行 DHCP**：
> 换个网口、等几分钟，或找学校网络中心。

> **显示乱码（奇怪的文字）**

### 「伪登录」是什么？

脚本**不信服务器说的"成功"**：登录接口返回成功后，还会真的去下载一次 HTTPS 网页内容来确认能不能上网
（校园网门户一般只劫持 HTTP，冒充不了 HTTPS 响应），所以被劫持的页面不会被误判成"已联网"。

出现"伪登录"通常是这三种情况：

1. **账号已在别处登录** → 用手机打开校园网登录页，点「注销 / 下线」，再回电脑重试；
2. **IP/MAC 不匹配** → `Win+R` 输入 `cmd`，执行 `ipconfig /release` 再 `ipconfig /renew`，然后重登；
3. **连错了网络**（比如连到手机热点）→ 切回校园网 / 校园 Wi-Fi 再试。

> 想看脚本到底收到了什么，就跑一次**登录联调**：
> `powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -TestLogin`
> 它会打印脱敏后的登录地址与服务器的**原始响应**（账号密码显示为 `***`）。

## 📝 六、给小白的提醒

### 安全

1. **密码安全**：密码用 Windows DPAPI 加密保存，只有本机、当前 Windows 用户能解密；换电脑或换账号后请重跑 `FirstTimeSetup.bat`；
2. **个人隐私**：不要在公用电脑保存你的配置；
3. **定期检查**：如果学校改了登录方式，需要更新脚本。

### 技巧

1. **先连接，后登录**：一定先插网线 / 连 WiFi，再运行脚本；
2. **看颜色判断**：✅ 绿色 = 成功；⚠️ 黄色 = 警告；❌ 红色 = 错误（需要处理）；
3. **日志很有用**：出问题就看 `logs\<日期>\CampusNet_Log.txt`。

### 备份

重要的是 `CampusNet_Config.json`（你的账号密码）与 `CampusNet_Login.ps1`（主程序）。**建议定期备份到 U 盘。**

### 7.1 一张图看懂协作关系

```
  你双击 CampusNet.bat
        │
        ▼

        ▼

        │  . 加载（点号加载，共享同一个内存空间）
        ▼
  CampusNet.Common.ps1 ──── 内核模块：53 个函数，所有真活都在这
        │
```

### 7.3 内核模块 `CampusNet.Common.ps1`（53 个函数，分 11 组）

> 这个文件是全部逻辑所在。下面按"干什么活"分组，改代码前先看这张地图。

#### ① 配置读写与元信息（6 个）

| 函数                                | 干什么                                                        |
|:----------------------------------- |:------------------------------------------------------------- |
| `Get-CampusNetVersion`              | 返回版本号（当前 `4.0`）                                       |
| `Get-DefaultSettings`               | 返回门户默认参数表（13 个 `Settings` 键，见 7.6）              |
| `Merge-CampusSettings`              | 把配置里的 `Settings` 合并到默认值之上，**只接受已知键**（拼错的键会被拒，避免静默失效） |
| `Save-CampusConfig`                 | 写配置：密码用 DPAPI 加密 + `icacls` 收窄文件权限              |
| `Load-CampusConfig`                 | 读配置：含老版本 Base64 密码 → DPAPI 的**一次性自动迁移**      |
| `Get-PortalErrorText`               | 门户错误码 → 中文说明                                          |

#### ② 日志与自动归档（7 个）

| 函数                        | 干什么                                                              |
|:--------------------------- |:------------------------------------------------------------------- |
| `Resolve-CampusLogDirName`  | 纯函数：把配置的日志目录名归一成安全名字，非法值（`..`、盘符、通配符）回落 `logs` |
| `Get-CampusLogDir`          | 纯函数：算出某一天的日志目录 `<脚本>\<LogDir>\yyyy-MM-dd`            |
| `Get-CampusLogFile`         | 纯函数：按种类（main / launcher / silent / fatal）算日志文件路径     |
| `Get-ExpiredLogDirs`        | 纯函数：算出超期日期目录（只认 `yyyy-MM-dd`，**当天与未来永不入选**） |
| `Clear-ExpiredCampusLogs`   | 建今天目录 + 删超期目录；只记日志，**永远不抛异常**                   |
| `Write-CampusLog`           | 写日志（超过 1MB 自动保留后一半轮转）；按级别着色上屏                |
| `Get-TextPreview`           | 把长文本压成一行并截断，用于日志与上屏                               |

#### ③ 凭据加密（DPAPI，2 个）

| 函数                       | 干什么                                                     |
|:-------------------------- |:---------------------------------------------------------- |
| `Protect-CampusPassword`   | 明文 → DPAPI 密文（`ConvertFrom-SecureString`）             |
| `Unprotect-CampusPassword` | 密文 → 明文，**只有本机、当前 Windows 用户**能解开          |

> 🔐 这不是 Base64（可逆编码），而是绑定"本机 + 当前用户"的加密。换电脑、换用户都解不开，必须重跑向导。

#### ④ 联网判定（防"伪登录"的底线，4 个）

| 函数                         | 干什么                                                                    |
|:---------------------------- |:------------------------------------------------------------------------- |
| `Get-InternetProbeList`      | 返回 HTTPS 联网探针候选，**已剔除门户下发的豁免域名**                       |
| `Test-CampusInternet`        | 【核心底线】真实联网校验：必须**下载到预期内容**才算通                      |
| `Test-InternetProbeResponse` | 纯函数：一次响应能否证明"真的在互联网上"（专门防门户劫持返回 200）           |
| `Wait-CampusInternet`        | 轮询等待联网恢复（默认 15 秒 / 每次 3 秒）                                  |

> ⚠️ **这是整个项目最重要的一条规则**：门户说"成功"不算成功，**能上外网才算**。

#### ⑤ 哆点协议加解密与 URL 构造（9 个）

| 函数                        | 干什么                                                             |
|:--------------------------- |:------------------------------------------------------------------ |
| `Get-DrappallKey`           | **由本机 IP 推导 XOR key**（IP 字符串每个字符 ASCII 逐位异或），**不是固定值** |
| `ConvertTo-DrappallValue`   | 每字符 XOR key 后写成 2 位十六进制（门户要求的参数混淆）             |
| `ConvertFrom-DrappallValue` | 逆运算（排障 / 测试用）                                             |
| `Get-MaskedUrl`             | 上屏与写日志前，把 `user_password` / `user_account` 换成 `***`       |
| `New-DrappallLoginUrl`      | 构造哆点 v4 登录 URL（**主路径**，全字段混淆）                       |
| `Get-DrappallReferer`       | 返回门户根地址作 `Referer`（门户只认这个头，不需要 Cookie）          |
| `New-DrappallLoadConfigUrl` | 构造 `loadConfig` URL（这个用 URL 编码的 base64，**不混淆**）          |

## 🔍 八、错误自检与排错（详细）

> 五章的"30 秒定位"没解决你的问题？这里给出全部细节。

### 8.1 退出码速查

| 码  | 含义                                                                                                                                   |
|:--- |:-------------------------------------------------------------------------------------------------------------------------------------- |
| 0   | 成功 / 当前已在线                                                                                                                      |
| 1   | 没有配置文件（跑一次 `FirstTimeSetup.bat`）；脚本抛未捕获异常也是 1（详见 `logs\<日期>\CampusNet_Fatal.log`）                                      |
| 2   | 配置文件损坏（解析 / 解密失败、字段缺失）→ 重跑 `FirstTimeSetup.bat`                                                                   |
| 3   | 没有可用网卡（已按 `-AdapterWaitSec` 等待过）。**`-Diagnose` 会逐张列出网卡以及不可用的原因**（例：只有 169.254.x.x = 没拿到 DHCP 租约） |
| 4   | 登录失败（含"伪登录"：接口说成功但实际没网）                                                                                           |
| 5   | `-Repair` 跑完仍未恢复可用 IPv4                                                                                                        |
| 6   | `-FlushDns` 清理 DNS 缓存失败（一般不需要管理员，失败时多半是权限问题）                                                                |

### 8.2 六个自检工具

#### ① `-Diagnose`：网络体检（**排查首选**）

```powershell
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -Diagnose
```

会依次打印：

1. **全量物理网卡体检表**：每张卡的状态、IP、SSID、网关，以及**被排除的原因**；
2. 最终选中的网卡；
3. **是否真能上互联网**（真实内容校验，不是 ping）；
4. 配置文件是否存在、日志文件在哪；
5. 门户 HTTP 探针结果：门户地址端口、**门户看到的你的 IP / MAC**、`WlanAcIp` / `WlanAcName`；
6. **接口形态**：主路径 `GET http://<host>:<port>/eportal/portal/login`（哆点 v4）、
   回退 `GET <BaseURL>?c=Portal&a=login`、以及 `loadConfig` 是否正常、`program_index` / `page_index` / `page_name`。

输出长这样：

```
物理网卡数量: 2（✔=可用，✘=不可用并附原因）
  [OK] 以太网   [以太网] 状态=Up IP=10.20.30.40 网关=True
  [!!] WLAN     [WiFi]  状态=Disconnected IP=169.254.142.113 网关=False
        → 无线未连接（Disconnected）：先连上校园 WiFi
```

#### ② `-TestLogin`：登录联调（**排查伪登录首选**）

```powershell
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -TestLogin
```

做的事：加载配置 → 选网卡 → 自动发现门户 → 打印探针预览 → 取 `loadConfig` 索引 →
**打印脱敏后的登录 URL**（账号密码显示为 `***`）→ 只发**一次**登录请求（超时 10 秒、不重试）→
打印**服务器原始响应**与解析结果 → 再跑一次真实联网校验，并**明确点出"伪登录"**。

#### ③ `-Repair` / 菜单 6：免重启网络修复

```powershell
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -Repair
```

**三步**：

| 步骤 | 做什么                                                                      | 需要管理员？ |
|:---- |:--------------------------------------------------------------------------- |:------------ |
| 1    | 清 DNS 缓存（**仅当** `FlushDnsOnRepair=1`，默认跳过）+ 清 ARP / 邻居缓存     | 清 ARP 需要 |
| 2    | 对"链路已连但没租约"的网卡做 **Release → Renew DHCP**                         | 不需要       |
| 3    | 网卡**仍不可用**时（不限于 APIPA）**重启网卡**（等价于重启电脑后重新初始化驱动），再 renew | **需要**     |

- 支持 `-DryRun`：只打印将要做什么，**不做任何改动**；
- 没有管理员时：**跳过需要管理员的两步**（清 ARP 缓存、重启网卡），
  **步骤 1 里的 DNS 清理（若开启）与步骤 2 的 DHCP 重新申请照常执行**，
  并提示你右键 `CampusNet.bat` → 以管理员身份运行；
- 只修**链路已 `Up`** 的网卡（无线断开的卡不算"该修"）；
- 退出码 `5` = 修完仍拿不到可用 IPv4。

#### ④ `-FlushDns` / 菜单 7：清 DNS 缓存（**独立功能**）

```powershell
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -FlushDns
```

- **不会**因为你点了"网络修复"就顺手跑一遍（想联动：配置 `"FlushDnsOnRepair": "1"`）；
- 只清本机 **DNS 客户端缓存**：不改网卡、不碰登录配置、**不需要管理员**；
- 会尝试报告清理前后条数；**本机读不到条数时只说"指令已执行"，绝不编造统计**；
- 退出码 `0` 成功 / `6` 失败（失败时多半是权限问题）。

### 8.3 提示语 → 原因 → 怎么办

| 你看到的提示 | 什么原因 | 怎么办 |
|:------------ |:-------- |:------ |
| 窗口一闪而过，什么都没发生 | 老版启动器的 `%errorlevel%` 在解析期就被展开，`pause` 从没执行到 | 已修：现在**无论成败都会停住**；若仍闪，用 `CampusNet_Debug.bat` |
| `密码解密失败：配置可能来自其他 Windows 用户或另一台电脑` | DPAPI 密文绑定"本机 + 当前用户"，换电脑 / 换用户 / 重装系统后解不开 | 删掉 `CampusNet_Config.json`，重跑 `FirstTimeSetup.bat` |
| `配置缺少账号或密码，请重新运行 FirstTimeSetup.bat` | 配置里的账号或密码为空 | 同上 |
| `检测到旧版 Base64 密码，正在迁移为 DPAPI 加密` | 老版本用的是可逆 Base64 | 正常现象，**自动迁移**，不用管 |
| `未找到具有有效 IPv4 地址的可用适配器。各网卡情况：` | 所有网卡都没有可用 IPv4 | 跑 `-Diagnose` 看原因；网线没插 / 没连 WiFi / 没拿到 DHCP |
| `提示：网卡只有 169.254.x.x（APIPA）表示没拿到 DHCP 租约…` | DHCP 租约没拿到，网卡停在自动私有地址 | 跑 `-Repair`（免重启修复） |
| `暂时没有可用网卡，等待网卡就绪（最多 N 秒）…` | 刚插网线 / 刚连 WiFi，系统还在拿 IP | 等它；静默版默认等 60 秒 |
| `无线网卡查不到当前 SSID（不一定代表没连上），继续尝试登录` | 无线驱动不报 SSID | 一般不用管，**只要拿到 IP 就会继续登录** |
| `门户探测到的 IP(...) 与网卡 IP(...) 不一致，以门户为准` | 网卡报的 IP 与门户看到的源 IP 不同（多网卡 / NAT） | 正常，脚本以门户为准 |
| `portal 自动发现：未探测到跳转（可能已联网或不在校园网内）` | 探针没被劫持 | 先确认是否已经能上网；不能就确认连的是校园网 |
| `门户判定请求参数非法（…）：XOR key 或参数形态不对，改走下一策略` | 参数混淆 key 算错或门户改了协议 | 多半是 `JsVersion` 等配置过期；跑 `-TestLogin` 看原始响应 |
| `portal 响应不可识别（HTTP 200）。原始响应预览：…` | 接口形态变了，返回的不是 JSONP | 看预览内容；若是一段 HTML 说明走错接口，可提 issue |
| `portal 拒绝登录请求：HTTP N` | 服务端拒绝（如 HTTP 500） | 看响应预览；换 `BaseURL` 或确认门户是否改版 |
| `网络异常，未取得服务器响应` | 网络不通 / 门户不可达 | 先 `-Diagnose` 确认链路与网关 |
| `伪登录：登录接口返回成功，但实际仍无法访问互联网。请检查：…` | 见五章的「伪登录」 | 按那三条依次排查 |
| `没找到任何物理网卡，无法修复。` | 系统里没有物理网卡（全被禁用？） | 检查设备管理器 |
| `没有需要修复的物理网卡：已经有一张网卡拿到了有效 IPv4 与网关。` | 网络其实是好的 | **不是故障**，去排别的问题 |
| `「…」重启网卡后仍未拿到 IPv4。这通常不是本机问题…` | 网络侧没放行 DHCP | 换网口 / 等几分钟 / 找网络中心 |
| `「…」仍未拿到 IPv4。重启网卡需要管理员权限…` | 第 3 步需要管理员 | 右键 `CampusNet.bat` → 以管理员身份运行 |
| `DNS 缓存清理失败：…：该操作需要管理员权限…` | 权限不足 | 同上 |
| `✘ 服务器说成功，但实际仍上不了网（伪登录）。` | 见五章的「伪登录」 | 按那三条依次排查 |
| `这是账号/密码类错误，打开浏览器也帮不上忙，所以这次不弹浏览器。` | 脚本按错误类型分流 | 重跑向导 / 去自助服务 |
| `这个账号已经在线上（可能还占着别的设备/会话）。` | `ret_code=2` | 去 `http://10.0.8.81:8080/Self/login/?302=LI` 下线其它设备 |
| 提示「找不到文件」 | 文件被分到不同目录了 | 所有 `.bat` / `.ps1` 必须**在同一目录** |
| 中文显示成乱码 | 终端编码问题 | 用 `CampusNet.bat` 启动（它会先 `chcp 65001`） |

### 8.4 门户返回的错误码速查

| `ret_code`  | 含义                         | 怎么办                                                             |
|:----------- |:---------------------------- |:------------------------------------------------------------------ |
| `1`         | **密码错误**                 | 核对密码；改过密码就重跑 `FirstTimeSetup.bat`                      |
| `2`         | 该账号已在其他设备登录       | 去自助服务下线其他设备：`http://10.0.8.81:8080/Self/login/?302=LI` |
| `3` / `4`   | 账号或密码错误 / 账号不存在  | 核对学号与密码                                                     |
| `8`         | IP/MAC 不匹配                | 确认在校园网内、重连后再试；可试 `ipconfig /release` 后 `/renew`    |
| `11`        | 账号已欠费或被限制           | 联系网络中心                                                       |
| 一大段 HTML | 响应不可识别（接口形态不对） | 多半没连校园网，或门户改了接口：跑 `-TestLogin` 看原始响应         |

### 8.5 登录失败时到底会不会弹浏览器

| 失败类型                                      | 行为                                                       |
|:--------------------------------------------- |:---------------------------------------------------------- |
| 密码错误 / 账号问题（`ret_code` 1、3、4、11） | **不弹浏览器**，提示重跑 `FirstTimeSetup.bat` 或去自助服务 |
| 账号已在线（`ret_code` 2）                    | **不弹浏览器**，提示去自助服务把其他设备下线               |
| 协议 / 网络类失败、伪登录                     | 打开门户页兜底，你点一下即可上网                           |

> 想彻底关掉弹浏览器：配置 `Settings` 里加 `"OpenPortalOnFailure": "0"`。**静默模式永远不弹窗。**

### 8.6 日志：在哪、看哪个、怎么清理

**统一放在 `CampusNet_AutoLogin\logs\<日期>\` 下**（例如 `logs\2026-09-28\`）：每天一个文件夹、
最多 4 个文件，不会再散落在脚本目录里。启动时会自动建好当天目录，并清理超过保留天数的旧目录
（默认保留 30 天；**当天与未来目录永不删**，非日期名的目录不碰）。启动时屏幕上还会打印一行
「日志目录：<完整路径>」，照着它去打开就行。

| 出什么情况                               | 看哪个文件                                                 |
|:---------------------------------------- |:---------------------------------------------------------- |
| 想知道"这次运行到底打印了什么"（交互版） | `CampusNet_Launcher.log`（本次运行的完整屏幕输出，覆盖）    |
| 开机自启 / 计划任务出问题                | `CampusNet_Silent.log`（静默版每次运行的完整输出）          |
| 想知道"历史上每次登录成没成"             | `CampusNet_Log.txt`（操作与登录记录，**追加**；超 1MB 截断一半） |
| 脚本**崩了**（异常、调用栈）             | `CampusNet_Fatal.log`（仅崩溃时生成）                       |

想改存放位置或保留天数：在 `CampusNet_Config.json` 的 `Settings` 里设 `"LogDir"`（默认 `"logs"`）
与 `"LogRetentionDays"`（默认 `"30"`，设 `"0"` = 永不清理）。

> 为何不用"启动器里 tee"：`& script *>&1 | Tee-Object -File ...` 会把任何非零的 `exit N`
> 压成 `1`，退出码就失真了（2/3/4 全变成 1）。所以改成脚本自己开 transcript，
> 启动器不接管输出，`%ERRORLEVEL%` 才能原样传回。

## 📚 九、技术原理（给好奇的小白）

### 脚本做了什么

```
1. 找身份证：获取电脑的 MAC 地址（像身份证号）
2. 找门牌号：获取电脑的 IP 地址（像家庭住址）
3. 算暗号：  用 IP 推导一个 key，把参数逐个字符 XOR 成十六进制（门户要求的格式）
4. 打电话：  把学号、暗号化的密码、MAC、IP 发给学校门户
5. 等回信：  接收门户回复，解析 result / ret_code
6. 亲自确认：不信门户的"成功"，自己再上一次网验证（这一步才是真判据）
7. 开门：    确认真的能上网，才告诉你"成功了"
```

### 门户拓扑

| 项目                   | 值                                                                                           |
|:---------------------- |:-------------------------------------------------------------------------------------------- |
| 门户入口页（80）       | `http://10.0.10.252/a79.htm?wlanusermac=…&wlanuserip=…&wlanacip=…`                           |
| **登录接口（主路径）** | `http://10.0.10.252:803/eportal/portal/login`（Dr.COM 哆点 v4）                              |
| 取页面配置             | `http://10.0.10.252:803/eportal/portal/page/loadConfig`（取 `program_index` / `page_index`） |
| 旧接口（自动回退）     | `http://10.0.10.252:801/eportal/?c=Portal&a=login`                                           |

- 登录参数按门户要求做 **逐字符 XOR + 十六进制**混淆，**XOR 的 key 由本机 IP 推导**：
  `key = IP 字符串每个字符 ASCII 码的逐位异或`（取自门户自带 JS `a41.js` 的 `util.getkey(term.ip)`）。
  脚本按当前网卡 IP 现算：**写死 `0x20` 会在别的网段被门户判为「请求参数包含非法内容」**（真实踩过，已修）；
- 未认证时用 `http://9.9.9.9/` 等探针自动发现真实的 `wlanuserip` / `wlanacip`；
- 探针会**自动避开**门户下发的 `visit_blacklist`（`1.1.1.1`、`generate_204`、`www.msftncsi.com` 等：
  这些地址门户不劫持，拿来做探针永远不会跳转）；
- 据抓包分析（结论已归档到 [`技术资料.md`](Campus%20Network%20source%20code/技术资料.md)）：**所有请求都是 GET、零 POST**；不需要 Cookie，只认 `Referer` + `User-Agent`。

### 为什么安全

1. **本地存储**：密码只存在你自己电脑上；
2. **本机加密**：DPAPI 绑定当前 Windows 用户，换电脑 / 换用户解不开；
3. **只发必要信息**：只发送登录所需字段；
4. **不落明文**：上屏与写日志前，账号与密码统一被 `Get-MaskedUrl` 换成 `***`。

## 🆘 十、紧急情况处理

### 情况一：脚本被误删

从备份 U 盘恢复，或重新下载一份。注意 `CampusNet_Config.json` 若丢失需重跑向导。

### 情况二：密码改了

运行 `FirstTimeSetup.bat`，重新输入新密码。

### 情况三：完全不能用

1. 手动打开门户页登录：`http://10.0.10.252/`；
2. 联系学校网络中心；
3. 把 `logs\<日期>\CampusNet_Launcher.log` 发给开发者，并说明"你做了什么、看到了什么"。
