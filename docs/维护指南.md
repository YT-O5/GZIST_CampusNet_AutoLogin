## 3. 核心数据流（改代码前先建立这个心智模型）

```
Load-CampusConfig            读配置、解 DPAPI 密码（失败区分 missing / corrupt）
      ↓
Get-CampusAdapter            选网卡（内部 Get-CampusAdapterReport 全量体检，绝不静默跳过）
      ↓
Wait-CampusInternet          已经能上网？→ 直接成功退出（0）
      ↓ 否
Get-LoginEndpoint            自动发现门户参数，决定登录用哪个 IP/MAC
      ↓                       （Resolve-CampusPortal → 探针 → ConvertFrom-PortalLocation）
Send-CampusLoginRequest      协议策略链：:803 portal/login → 失败再试 :801 旧接口
      ↓                       （URL 由 New-DrappallLoginUrl 拼，key 由 Get-DrappallKey 从 IP 推导）
Wait-CampusInternet          【底线】真实联网过了才算成功，否则一律失败（4）
```

**最重要的一条设计约束：`result:1`（协议层成功）≠ 能上网。**
门户在账号已在线、限速、AC 异常等情况下都可能回 `result:1`，所以判定成功永远以
`Wait-CampusInternet` 为准。这就是历史上"伪登录"问题的根治方式：**别把它改回去**。

## 4. 常见改动任务 → 改哪里

| 你想做的事 | 改哪里 | 注意 |
| --- | --- | --- |
| 换门户地址 / 端口 | `CampusNet_Config.json` 的 `Settings.PortalHost` / `PortalPort` | 一般不用改代码，发现逻辑会自动探 |
| 门户升级后登录失败 | 先跑 `-Diagnose` 看最终接口形态，再对照 `Campus Network source code/captures/README.md` | 大概率是 `jsVersion` 变了 |
| 参数编码规则变了 | `Get-DrappallKey` / `ConvertTo-DrappallValue` | 有 HAR 真实向量测试，改错会立刻红 |
| 新增一种登录协议 | `Send-CampusLoginRequest` 的策略链 + `New-*LoginUrl` | 记得加"响应不可识别就换下一种"的分支 |
| 改失败后的行为（开不开浏览器） | `Get-CampusFailureAction` | 凭证/在线类**不应该**开浏览器 |
| 改退出码 | `Invoke-CampusSilentLogin` + `CampusNet_Login.ps1` 末尾 | 退出码在三处文档里都有，要同步 |
| 加一个菜单项 | `Show-MainMenu`（Common 无关） | 同时更新 `README.md` 的菜单表和 `CampusNet.bat` 提示 |
| 加一个独立小功能 | `Common.ps1` 加函数 + 入口加开关 + 写单测 | 参考 `-FlushDns` 的做法（它就是独立的，不挂在别的流程里） |
| 改配置项 | `Get-DefaultSettings` + `CampusNet_Config.example.json` + README | 三个地方要一致 |

## 5. 踩过的坑（真的踩过，别重复）

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 双击 bat 窗口一闪就没了 | `%errorlevel%` 在 cmd 解析整行时就展开了，`pause` 条件永远为假 | 先 `set "RC=%ERRORLEVEL%"` 再判断，并**无条件 pause** |
| .ps1 里中文报语法错 | 文件存成了无 BOM 的 UTF-8，PS 5.1 按 ANSI 读 | **所有 .ps1 必须 UTF-8 with BOM** |
| 日志里出现明文密码 | 直接把带密码的 URL 写进日志/上屏 | 一律过 `Get-MaskedUrl` |
| 门户回 `403 请求参数包含非法内容` | XOR key 写死成 0x20，但 key 应该由本机 IP 推导 | 用 `Get-DrappallKey -IP` |
| 回退接口 URL 前缀莫名消失 | 双引号里 `"$base?"` 被当成变量名 `base?` | 改成显式拼接（见 `Get-CampusPortalPageUrl`） |
| 网线插上却"没有可用网卡" | 网卡只有 APIPA(169.254.x.x)，实际没拿到 DHCP 租约 | 跑菜单 6 `-Repair`；体检表会写明原因 |
| 重启才好使 | 驱动没重新初始化 / DHCP 租约卡住 | `-Repair` 做 release+renew，必要时重启网卡 |
| Pester Mock 报参数不匹配 | Mock 没带生产代码用的 `-ErrorAction` | Mock 的参数形态要和生产一致 |

## 6. 安全须知（交接时务必交代）

1. **密码存储**：`CampusNet_Config.json` 里的密码是 **DPAPI 密文**，只能在**本机 + 当前 Windows 用户**下解开。
   拷到别人机器上解不开，这是有意的。
2. **别提交这些**：`CampusNet_Config.json`、日志、`CampusNet_Diag.json`、抓包 `*.har`
：已全部在 `.gitignore` 里，并且这套规则**用真实 git 验证过**。被忽略的逐个列出：
   `CampusNet_AutoLogin/CampusNet_Config.json`、`CampusNet_AutoLogin/logs/`（整目录：当天日志 +
   `_legacy/` 旧日志）、`CampusNet_AutoLogin/CampusNet_Log.txt`（旧位置，防御性保留）、
   `CampusNet_AutoLogin/CampusNet_Diag.json`、`/CampusNet_Log.txt`（项目根，防御性规则）、
   `*.har`（**全局忽略、无任何例外**：门户那套逐字符 XOR 只是编码不是加密，
   名为 `redacted` 的 HAR 里凭据依旧可还原：2026-09-28 已因此删掉曾经入库的那份）。
   另外 `/CampusNet_Log.txt` 是**防御性规则**：脚本实际只往 `CampusNet_AutoLogin\logs\` 里写日志，
   但万一有人在项目根目录跑，也不会把日志带进仓库（已用 `git check-ignore` 验证过
   `*.log` 不会匹配 `CampusNet_Log.txt`，所以要单独写一条）。
   **改 .gitignore 前先想清楚**：漏一条就可能把凭据提交上去。
3. **抓包文件含可还原的凭据**：门户的参数混淆只是 XOR，**不是加密**。要分享请用
   `Campus Network source code/captures/`（该抓包已按隐私要求删除；`.gitignore` 对 `*.har` 是全局忽略、**不开任何例外**）。
4. **日志/文档/测试里不要出现真实学号或密码**：文档用 `<学号>`，测试用示例值（如 `135790`）。
   已经做成这样了，保持住。
5. **静默路径绝对不能弹窗**：见 `CampusNet_Silent.ps1` 头部的维护须知。

## 7. 提交前自检清单

### 已装了 pre-commit 钩子（`git config core.hooksPath .githooks`）

`.githooks/pre-commit` 会在提交落盘前检查暂存区，**把 `CampusNet_Config.json`、`*.har`、
`logs/`、各类日志、`.saz`/`.pcap` 等直接拒掉**。原因：`.gitignore` 只拦得住常规 `git add`，
一旦有人手滑 `git add -f`，忽略规则就形同虚设：钩子是那道"落盘前再看一眼"的兜底。

- 新克隆的仓库需要**各自执行一次** `git config core.hooksPath .githooks`（该配置是本地级的，不会随仓库分发）；
- 钩子被拒后撤回暂存：`git restore --staged <文件>`；
- 确认已脱敏要强推：`git commit --no-verify`（与 `-f` 一样是唯一突破口，慎用）。

```powershell
# 1) 语法（内置在项目里，交接后也可用）
npm run check
# 2) 测试（npm test 会自动先跑一遍语法自检）
npm test
# 3) 确认没把凭据带进可入库文件（把下面尖括号换成你自己的真实值再跑；
#    ⚠️ 千万不要把替换后的真实值提交进来）
git status --short
git diff --cached | findstr /I "<你的学号> <你的密码>"   # 应无输出
# 4) 改过协议相关代码，额外跑一次真机验证
powershell -NoProfile -ExecutionPolicy Bypass -File .\CampusNet_AutoLogin\CampusNet_Login.ps1 -TestLogin
```

## 8. 交接时可以这样讲（一段话版本）

> 这个工具会自动帮你连校园网。逻辑全在 `CampusNet.Common.ps1`，`CampusNet_Login.ps1` 只是菜单壳子。
> 它先找一张能用的网卡，探测门户真实参数，然后按哆点协议发登录请求；**发完一定要再真连一次外网才算成功**，
> 这是为了防"看着登上了其实没网"。参数里的密码是 XOR 混淆的，**key 由本机 IP 推导**，不是固定值：
> 这是最容易改错的地方。协议细节和抓包证据都在 `Campus Network source code/captures/`，
> 那里还有门户源码的逐行注释解读版，想搞懂认证原理看那个。改完跑 `npm test`。
