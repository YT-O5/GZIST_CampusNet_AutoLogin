## 3. 核心数据流（改代码前先建立这个心智模型）

```
Load-CampusConfig            读配置、解 DPAPI 密码（失败区分 missing / corrupt）
      ↓
Get-CampusAdapter            选网卡（内部 Get-CampusAdapterReport 全量体检，绝不静默跳过）
      ↓
Wait-CampusInternet          已经能上网？→ 直接成功退出（0）
      ↓ 否
Get-LoginEndpoint            自动发现门户参数，决定登录用哪个 IP/MAC
      ↓                       （Resolve-CampusPortal → 探针 → ConvertFrom-PortalLocation）
Send-CampusLoginRequest      协议策略链：:803 portal/login → 失败再试 :801 旧接口
      ↓                       （URL 由 New-DrappallLoginUrl 拼，key 由 Get-DrappallKey 从 IP 推导）
Wait-CampusInternet          【底线】真实联网过了才算成功，否则一律失败（4）
```

**最重要的一条设计约束：`result:1`（协议层成功）≠ 能上网。**
门户在账号已在线、限速、AC 异常等情况下都可能回 `result:1`，所以判定成功永远以
`Wait-CampusInternet` 为准。这就是历史上"伪登录"问题的根治方式：**别把它改回去**。

## 5. 踩过的坑（真的踩过，别重复）

| 现象                              | 原因                                                           | 修法                                                  |
| --------------------------------- | -------------------------------------------------------------- | ----------------------------------------------------- |
| 双击 bat 窗口一闪就没了           | `%errorlevel%` 在 cmd 解析整行时就展开了，`pause` 条件永远为假 | 先 `set "RC=%ERRORLEVEL%"` 再判断，并**无条件 pause** |
| .ps1 里中文报语法错               | 文件存成了无 BOM 的 UTF-8，PS 5.1 按 ANSI 读                   | **所有 .ps1 必须 UTF-8 with BOM**                     |
| 日志里出现明文密码                | 直接把带密码的 URL 写进日志/上屏                               | 一律过 `Get-MaskedUrl`                                |
| 门户回 `403 请求参数包含非法内容` | XOR key 写死成 0x20，但 key 应该由本机 IP 推导                 | 用 `Get-DrappallKey -IP`                              |
| 回退接口 URL 前缀莫名消失         | 双引号里 `"$base?"` 被当成变量名 `base?`                       | 改成显式拼接（见 `Get-CampusPortalPageUrl`）          |
| 网线插上却"没有可用网卡"          | 网卡只有 APIPA(169.254.x.x)，实际没拿到 DHCP 租约              | 跑菜单 6 `-Repair`；体检表会写明原因                  |
| 重启才好使                        | 驱动没重新初始化 / DHCP 租约卡住                               | `-Repair` 做 release+renew，必要时重启网卡            |
| Pester Mock 报参数不匹配          | Mock 没带生产代码用的 `-ErrorAction`                           | Mock 的参数形态要和生产一致                           |

## 6. 安全须知（交接时务必交代）

1. **密码存储**：`CampusNet_Config.json` 里的密码是 **DPAPI 密文**，只能在**本机 + 当前 Windows 用户**下解开。
   拷到别人机器上解不开，这是有意的。
2. **别提交这些**：`CampusNet_Config.json`、日志、`CampusNet_Diag.json`、抓包 `*.har`
   这些都**已全部在 `.gitignore` 里**，并且这套规则**用真实 git 验证过**。被忽略的逐个列出：
   `CampusNet_AutoLogin/CampusNet_Config.json`、`CampusNet_AutoLogin/logs/`（整目录：当天日志 +
   `_legacy/` 旧日志）、`CampusNet_AutoLogin/CampusNet_Log.txt`（旧位置，防御性保留）、
   `CampusNet_AutoLogin/CampusNet_Diag.json`、`/CampusNet_Log.txt`（项目根，防御性规则）、
   `*.har`（**全局忽略、无任何例外**：门户那套逐字符 XOR 只是编码不是加密，
   名为 `redacted` 的 HAR 里凭据依旧可还原：2026-09-28 已因此删掉曾经入库的那份）。
   另外 `/CampusNet_Log.txt` 是**防御性规则**：脚本实际只往 `CampusNet_AutoLogin\logs\` 里写日志，
   但万一有人在项目根目录跑，也不会把日志带进仓库（已用 `git check-ignore` 验证过
   `*.log` 不会匹配 `CampusNet_Log.txt`，所以要单独写一条）。
   **改 .gitignore 前先想清楚**：漏一条就可能把凭据提交上去。
3. **抓包文件含可还原的凭据**：门户的参数混淆只是 XOR，**不是加密**。要分享请用
   `Campus Network source code/captures/`（该抓包已按隐私要求删除；`.gitignore` 对 `*.har` 是全局忽略、**不开任何例外**）。
4. **日志/文档/测试里不要出现真实学号或密码**：文档用 `<学号>`，测试用示例值（如 `135790`）。
   已经做成这样了，保持住。
5. **静默路径绝对不能弹窗**：见 `CampusNet_Silent.ps1` 头部的维护须知。

## 7. 提交前自检清单

### 已装了 pre-commit 钩子（`git config core.hooksPath .githooks`）

`.githooks/pre-commit` 会在提交落盘前检查暂存区，**把 `CampusNet_Config.json`、`*.har`、
`logs/`、各类日志、`.saz`/`.pcap` 等直接拒掉**。原因：`.gitignore` 只拦得住常规 `git add`，
一旦有人手滑 `git add -f`，忽略规则就形同虚设：钩子是那道"落盘前再看一眼"的兜底。

- 新克隆的仓库需要**各自执行一次** `git config core.hooksPath .githooks`（该配置是本地级的，不会随仓库分发）；
- 钩子被拒后撤回暂存：`git restore --staged <文件>`；
- 确认已脱敏要强推：`git commit --no-verify`（与 `-f` 一样是唯一突破口，慎用）。

```powershell
# 1) 语法（内置在项目里，交接后也可用）
npm run check
# 2) 测试（npm test 会自动先跑一遍语法自检）
npm test
# 3) 确认没把凭据带进可入库文件（把尖括号换成真实值后再跑；
#    ⚠️ 千万不要把替换后的真实值提交进来）
git status --short
git diff --cached | findstr /I "<学号> <密码>"   # 应无输出
# 4) 改过协议相关代码，额外跑一次真机验证
powershell -NoProfile -ExecutionPolicy Bypass -File .\CampusNet_AutoLogin\CampusNet_Login.ps1 -TestLogin
```

## 8. 交接时可以这样讲（一段话版本）

> 该工具会自动连校园网。逻辑全在 `CampusNet.Common.ps1`，`CampusNet_Login.ps1` 只是菜单壳子。
> 它先找一张能用的网卡，探测门户真实参数，然后按哆点协议发登录请求；**发完一定要再真连一次外网才算成功**，
> 这是为了防"看着登上了其实没网"。参数里的密码是 XOR 混淆的，**key 由本机 IP 推导**，不是固定值：
> 这是最容易改错的地方。协议细节和抓包证据都在 `Campus Network source code/captures/`，
> 那里还有门户源码的逐行注释解读版，想搞懂认证原理看那个。改完跑 `npm test`。

### 7.3 内核模块 `CampusNet.Common.ps1`（54 个函数，分 11 组）

> 这个文件是全部逻辑所在。下面按"干什么活"分组，改代码前先看这张地图。

#### ① 配置读写与元信息（6 个）

| 函数                                | 干什么                                                        |
|:----------------------------------- |:------------------------------------------------------------- |
| `Get-CampusNetVersion`              | 返回版本号（当前 `4.0`）                                       |
| `Get-DefaultSettings`               | 返回门户默认参数表（13 个 `Settings` 键，见 7.6）              |
| `Merge-CampusSettings`              | 把配置里的 `Settings` 合并到默认值之上，**只接受已知键**（拼错的键会被拒，避免静默失效） |

| `Load-CampusConfig`                 | 读配置：含老版本 Base64 密码 → DPAPI 的**一次性自动迁移**      |
| `Get-PortalErrorText`               | 门户错误码 → 中文说明                                          |

#### ② 日志与自动归档（7 个）

| 函数                        | 干什么                                                              |
|:--------------------------- |:------------------------------------------------------------------- |
| `Resolve-CampusLogDirName`  | 纯函数：把配置的日志目录名归一成安全名字，非法值（`..`、盘符、通配符）回落 `logs` |

| `Get-TextPreview`           | 把长文本压成一行并截断，用于日志与上屏                               |

#### ③ 凭据加密（DPAPI，2 个）

| 函数                       | 干什么                                                     |
|:-------------------------- |:---------------------------------------------------------- |
| `Protect-CampusPassword`   | 明文 → DPAPI 密文（`ConvertFrom-SecureString`）             |
| `Unprotect-CampusPassword` | 密文 → 明文，**只有本机、当前 Windows 用户**能解开          |

> 🔐 这不是 Base64（可逆编码），而是绑定"本机 + 当前用户"的加密。换电脑、换用户都解不开，必须重跑向导。

#### ④ 联网判定（防"伪登录"的底线，4 个）

| 函数                         | 干什么                                                                    |
|:---------------------------- |:------------------------------------------------------------------------- |
| `Get-InternetProbeList`      | 返回 HTTPS 联网探针候选，**已剔除门户下发的豁免域名**                       |
| `Test-CampusInternet`        | 【核心底线】真实联网校验：必须**下载到预期内容**才算通                      |
| `Test-InternetProbeResponse` | 纯函数：一次响应能否证明"真的在互联网上"（专门防门户劫持返回 200）           |
| `Wait-CampusInternet`        | 轮询等待联网恢复（默认 15 秒 / 每次 3 秒）                                  |

> ⚠️ **这是整个项目最重要的一条规则**：门户说"成功"不算成功，**能上外网才算**。

#### ⑤ 哆点协议加解密与 URL 构造（9 个）

| 函数                        | 干什么                                                             |
|:--------------------------- |:------------------------------------------------------------------ |
| `Get-DrappallKey`           | **由本机 IP 推导 XOR key**（IP 字符串每个字符 ASCII 逐位异或），**不是固定值** |
| `ConvertTo-DrappallValue`   | 每字符 XOR key 后写成 2 位十六进制（门户要求的参数混淆）             |
| `ConvertFrom-DrappallValue` | 逆运算（排障 / 测试用）                                             |
| `Get-MaskedUrl`             | 上屏与写日志前，把 `user_password` / `user_account` 换成 `***`       |
| `New-DrappallLoginUrl`      | 构造哆点 v4 登录 URL（**主路径**，全字段混淆）                       |
| `Get-DrappallReferer`       | 返回门户根地址作 `Referer`（门户只认这个头，不需要 Cookie）          |
| `New-DrappallLoadConfigUrl` | 构造 `loadConfig` URL（这个用 URL 编码的 base64，**不混淆**）          |
| `Get-DrappallPageIndex`     | 请求 `loadConfig`，拿 `program_index` / `page_index`                |
| `New-CampusLoginUrl`        | 构造旧接口（`:801 ?c=Portal&a=login`）URL，**只在主路径失败时回退用** |

> 📌 写死 `0x20` 会在别的网段被门户判为「请求参数包含非法内容」：这个坑真实踩过，所以改成按当前 IP 现算。

#### ⑥ 门户自动发现（6 个）

| 函数                         | 干什么                                                            |
|:---------------------------- |:----------------------------------------------------------------- |
| `ConvertFrom-PortalLocation` | 纯函数：从跳转地址 / 页面里解析门户地址与 AC 参数                  |
| `Get-DefaultProbeBlacklist`  | 门户下发的 `visit_blacklist`（那些地址门户**不劫持**，做探针永远不跳转） |
| `Get-PortalProbeUrls`        | 过滤掉黑名单后的探针 URL 列表                                      |
| `Get-CampusPortalProbe`      | 发 HTTP 探针，取回跳转页 / `Location`                              |
| `Resolve-CampusPortal`       | 探针 → 解析 → 把非空值合并回 `Settings`（会就地改配置）             |
| `Get-LoginEndpoint`          | 决定登录用哪个 IP / MAC（**以门户看到的为准**，网卡报的不一定对）   |

#### ⑦ 失败兜底与门户页辅助（4 个）

| 函数                        | 干什么                                                              |
|:--------------------------- |:------------------------------------------------------------------- |
| `Test-CampusSettingEnabled` | 读布尔型配置（`1`/`0`、`true`/`false` 都认；默认值为空时用传入的默认） |
| `Get-CampusFailureAction`   | 纯函数：失败后该干什么：`credentials`（引导改密码）/ `online`（引导下线）/ `browser`（开浏览器兜底）/ `none` |
| `Get-CampusPortalPageUrl`   | 拼出门户入口页 `a79.htm?wlanusermac=…&wlanuserip=…&wlanacip=…`（手工登录用） |
| `Open-CampusPortalPage`     | 用默认浏览器打开门户页（**仅交互模式**；静默模式永不弹窗）             |

> 💡 这一组就是「登录失败后到底要不要弹浏览器」的决策中枢：**密码错不弹、已在线不弹、协议/网络类失败才弹**。

#### ⑧ 网卡体检与选择（6 个）

| 函数                            | 干什么                                                                |
|:------------------------------- |:--------------------------------------------------------------------- |
| `Get-CampusAdapterType`         | 判 WiFi / 以太网 / 虚拟                                                 |
| `Select-CampusAdapterByRoute`   | 纯函数：按"去往门户服务器走哪张网卡"挑（比"优先有线"更准）              |
| `Test-CampusIsAdmin`            | 当前是否管理员运行                                                     |
| `Get-CampusAdapterRejectReason` | 纯函数：给出某张网卡"为什么不可用"的具体原因                          |
| `Get-CampusAdapterReport`       | **全量网卡体检表**：每张物理网卡都列出来，**绝不静默跳过**              |
| `Get-CampusAdapter`             | 挑一张可用网卡（路由优先 → 有网关 → 有线优先）                          |

> 💡 为什么要"绝不静默跳过"：以前只报"没有可用网卡"，无法得知是哪张、为什么。
> 现在每张卡都会写明状态与原因（例：`只有 169.254.x.x = 没拿到 DHCP 租约`）。

#### ⑩ 响应解析与发送（2 个）

| 函数                         | 干什么                                                                   |
|:---------------------------- |:------------------------------------------------------------------------ |

### 7.4 交互入口 `CampusNet_Login.ps1`

**主菜单（1-8）原文：**

```
1. 重新测试网络连接
2. 手动登录尝试
3. 修改账号 / 服务器设置
4. 查看最近日志
5. 登录联调（打印服务器原始响应）
6. 网络修复（免重启：重拿 DHCP / 必要时重启网卡）
7. 清理 DNS 缓存
8. 退出
```

菜单顶部会先打印当前账号 / 服务器与网卡信息，并**自动尝试登录一次并确认联网**，所以多数时候双击完即可。

**命令行开关：**

| 开关         | 作用                     | 退出码               |
|:------------ |:------------------------ |:-------------------- |
| `-Setup`     | 只跑首次设置向导         | 成功 `0` / 失败 `1`  |
| `-Silent`    | 静默登录（同静默版）     | 透传 `0`-`4`         |
| `-Diagnose`  | 网络诊断（见《使用说明》8.2 ①）     | 恒 `0`               |
| `-TestLogin` | 登录联调，打印原始响应   | 恒 `0`               |
| `-Repair`    | 免重启网络修复           | 成功 `0` / 未修复 `5` |
| `-FlushDns`  | 只清 DNS 客户端缓存      | 成功 `0` / 失败 `6`  |
| （无参数）   | 打开主菜单               | `0`                  |

### 7.5 静默入口 `CampusNet_Silent.ps1`

| 参数              | 默认 | 作用                      |
|:----------------- |:---- |:------------------------- |
| `-MaxAttempts`    | `3`  | 每次登录的重试次数        |
