## 1️⃣ 双击后窗口一闪就没

**原因**：脚本还没跑到"暂停"就退出了，或启动器被当成管道调用导致退出码失真。

**做法**：改用 `CampusNet_Debug.bat` 启动：它加了 `-NoExit`，窗口不关，报错直接看得见。

**还不行**：打开 `logs\<今天>\CampusNet_Launcher.log`，看最后几行。
启动器现在**无论成败都会停住**并显示 `Press any key to close this window...`，所以正常情况下不该再闪退。

## 2️⃣ 网络类：没网卡 / 只有 169.254 / 插网线没反应

这三种通常是同一件事：**网卡没拿到 DHCP 租约**，只剩 `169.254.x.x` 这种自分配地址。

### 免重启修复：主菜单 `6`（或 `-Repair`）

```powershell
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -Repair
```

**三步**：

| 步骤 | 做什么                                            | 需要管理员？ |
|:---- |:------------------------------------------------- |:------------ |
| 1    | 清 DNS 缓存（仅当 `FlushDnsOnRepair=1`）+ 清 ARP / 邻居缓存 | 清 ARP 需要 |
| 2    | 对"链路已连但没租约"的网卡做 Release → Renew DHCP | 不需要       |
| 3    | 仍不可用时重启网卡（等价于重启后重新初始化驱动）  | **需要**     |

- 想先看看它要做什么、不实际执行：加 `-DryRun`；
- **没有管理员时**：跳过"清 ARP"与"重启网卡"两步，DNS 清理（若开启）与 DHCP 重新申请照常执行；
- 想以管理员运行：右键 `CampusNet.bat` → 以管理员身份运行；
- 退出码 `5` = 修完仍拿不到可用 IPv4。

> ⚠️ 三步做完还是不行，**多半不是本机问题**，而是网络侧没放行 DHCP（端口/MAC 绑定、需重新认证，或该口不在校园网）。
> 换个网口、等几分钟，或找学校网络中心。

**想看每张网卡为什么被排除**：跑诊断（见 §8）。

## 3️⃣ 账号类：密码错 / 已在别处登录 / 解密失败

| 提示 | 什么原因 | 怎么办 |
|:---- |:-------- |:------ |
| `密码错误`、`ret_code:1/3/4` | 账号或密码不对 | 核对后重跑 `FirstTimeSetup.bat`；若刚改过密码必须重跑 |
| `已在其他设备登录`、`ret_code:2`、`AC999` | 该账号在别处还占着会话 | 去自助服务下线其它设备：`http://10.0.8.81:8080/Self/login/?302=LI` |
| `密码解密失败：配置可能来自其他 Windows 用户或另一台电脑` | 密码用 DPAPI 加密，绑定"本机 + 当前用户"，换电脑/换用户/重装系统都解不开 | 删掉 `CampusNet_Config.json`，重跑 `FirstTimeSetup.bat` |
| `配置缺少账号或密码` | 配置里的账号或密码为空 | 同上 |
| `检测到旧版 Base64 密码，正在迁移为 DPAPI 加密` | 老版本用可逆 Base64 | **正常现象**，自动迁移，不用管 |

**换电脑 / 多人共用一台电脑**：重跑 `FirstTimeSetup.bat` 输入新账号，旧配置会被覆盖。

> 💡 这类错误**不会**弹浏览器：脚本判断"开浏览器也帮不上忙"（见 §4 的分流表）。

## 4️⃣ "伪登录"：提示成功却上不了网

脚本**不信服务器说的"成功"**：登录接口返回成功后，还会真的下载一次 **HTTPS 网页内容**来确认能不能上网
（校园网门户一般只劫持 HTTP，冒充不了 HTTPS 响应），所以被劫持的页面不会被误判成"已联网"。
**只有真实联网校验通过才算成功。**

**三条常见原因，依次排查**：

1. **账号已在别处登录** → 用手机打开校园网登录页，点「注销 / 下线」，再回电脑重试；
2. **IP/MAC 不匹配** → `Win+R` 输入 `cmd`，执行 `ipconfig /release` 再 `ipconfig /renew`，然后重登；
3. **连错了网络**（比如连到手机热点） → 切回校园网 / 校园 Wi-Fi 再试。

**想看脚本到底收到了什么**：跑**登录联调**：

```powershell
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -TestLogin
```

它会打印**脱敏后的登录地址**（账号密码显示为 `***`）与**服务器原始响应**，再跑一次真实联网校验并明确点出"伪登录"。

### 登录失败时到底会不会弹浏览器？

| 失败类型 | 行为 |
|:-------- |:---- |
| 密码错误 / 账号问题（`ret_code` 1、3、4、11） | **不弹**，提示重跑向导或去自助服务 |
| 账号已在线（`ret_code` 2） | **不弹**，提示去自助服务下线其它设备 |
| 协议 / 网络类失败、伪登录 | 打开门户页兜底，你点一下即可上网 |

想彻底关掉：配置 `Settings` 里加 `"OpenPortalOnFailure": "0"`。**静默模式永远不弹窗。**

## 5️⃣ 能上 QQ、打不开网页（DNS）

这是"域名解析"问题，不是登录问题。

**做法**：主菜单 `7`（或命令行 `-FlushDns`）：

```powershell
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -FlushDns
```

- 只清**本机 DNS 客户端缓存**：不改网卡、不碰登录配置、**不需要管理员**；
- **独立功能**：不会因为你点了"网络修复"就顺手跑一遍（想联动：配置 `"FlushDnsOnRepair": "1"`）；
- 会报告清理前后条数；**本机读不到条数时只说"指令已执行"，不编造统计**；
- 退出码 `0` 成功 / `6` 失败（失败多半是权限问题）。

## 6️⃣ 想开机自动登录

1. `Win+R` 输入 `taskschd.msc` 打开任务计划；
2. 新建基本任务：名称自取；触发器选「计算机启动时」或「计算机登录时」；操作选「启动程序」；
3. 「程序或脚本」填 `powershell.exe`；
4. 「添加参数」填 `-NoProfile -ExecutionPolicy Bypass -File "<本目录>\CampusNet_Silent.ps1"`；
5. 完成。

> ⚠️ **千万不要用 `CampusNet.bat`**：那是交互版，每次开机都会弹窗并一直等你按键。
> 静默版 `CampusNet_Silent.ps1` 无窗口，结果用退出码表示（0 成功 / 4 失败），默认还会等网卡最多 60 秒。

## 7️⃣ 日志：在哪、看哪个

**统一在 `CampusNet_AutoLogin\logs\<日期>\`**（例如 `logs\2026-09-28\`）：每天一个文件夹、最多 4 个文件。
启动时会自动建当天目录，并按保留天数清理旧目录（默认 30 天；**当天与未来永不删**）。
启动时屏幕会打印一行「日志目录：<完整路径>」。

| 出什么情况 | 看哪个 |
|:---------- |:------ |
| 这次运行到底打印了什么（交互版） | `CampusNet_Launcher.log`（每次运行覆盖） |
| 开机自启 / 计划任务出问题 | `CampusNet_Silent.log` |
| 历史上每次登录成没成 | `CampusNet_Log.txt`（**追加**；超 1MB 截断一半） |
| 脚本崩了（异常、调用栈） | `CampusNet_Fatal.log`（仅崩溃时生成） |

改存放位置或保留天数：配置 `Settings` 里的 `"LogDir"`（默认 `"logs"`）与 `"LogRetentionDays"`（默认 `"30"`，`"0"` = 永不清理）。

## 8️⃣ 命令速查 + 退出码

```powershell
# 网络体检：全量网卡（含每张被排除的原因）+ 是否真能上网 + 门户探测
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -Diagnose

# 登录联调：脱敏登录 URL + 服务器原始响应 + 真实联网校验   ← 排查"伪登录"首选
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -TestLogin

# 免重启网络修复（清缓存 → 重拿 DHCP → 必要时重启网卡；后两项之外见 §2）
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -Repair

# 只清 DNS 缓存（独立功能，不与"网络修复"混在一起）
powershell -ExecutionPolicy Bypass -File .\CampusNet_Login.ps1 -FlushDns

# 静默登录并查看退出码
powershell -ExecutionPolicy Bypass -File .\CampusNet_Silent.ps1 ; echo $LASTEXITCODE
```

| 开关 | 作用 | 退出码 |
|:---- |:---- |:------ |
| `-Setup` | 只跑首次设置向导 | `0` 成功 / `1` 失败 |
| `-Silent` | 静默登录 | 透传 `0`-`4` |
| `-Diagnose` | 网络诊断 | 恒 `0` |
| `-TestLogin` | 登录联调 | 恒 `0` |
| `-Repair` | 免重启网络修复 | `0` / `5` |
| `-FlushDns` | 只清 DNS 缓存 | `0` / `6` |

| 退出码 | 含义 |
|:------ |:---- |
| `0` | 成功 / 当前已在线 |
| `1` | 没有配置文件（跑 `FirstTimeSetup.bat`）；脚本抛未捕获异常也是 1（看 `CampusNet_Fatal.log`） |
| `2` | 配置文件损坏（解析 / 解密失败、字段缺失）→ 重跑向导 |
| `3` | 没有可用网卡（已按 `-AdapterWaitSec` 等待过）→ 跑 `-Diagnose` 看每张卡的原因 |
| `4` | 登录失败（含"伪登录"） |
| `5` | `-Repair` 跑完仍未恢复可用 IPv4 |
| `6` | `-FlushDns` 清理失败（多半是权限问题） |

## 9️⃣ 完全不能用 / 怎么求助

1. **手工登录**：浏览器打开门户页 `http://10.0.10.252/`，能上网就说明脚本的问题可以慢慢查；
2. **联系**广州理工学院网络中心（账号、DHCP、端口的网络侧问题）；
3. **求助时请附上**：`logs\<今天>\CampusNet_Launcher.log` 全文 + 退出码 + `-TestLogin` 的输出
   + 一句话说明"你做了什么、看到了什么"。
